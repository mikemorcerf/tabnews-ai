# tabnews-ai

Development of the platform Tab News using agentic development.

## Stack

- Next.js (App Router, under `app/`), React, plain JavaScript (no TypeScript); exact versions are pinned in `package.json`
- Keep it minimal: the least code possible, following modern Next.js conventions

## Commands

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm start` — serve the production build

## Deployment

- GitHub: https://github.com/mikemorcerf/tabnews-ai
- Vercel deploys every push to `main` automatically: https://tabnews-ai.vercel.app
